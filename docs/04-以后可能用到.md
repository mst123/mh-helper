# 以后可能用到

2026-10-11 看过 `AzurLaneAutoScript`、`Maa_MHXY` 和 `Java_MHXYdemo`。已经写进程序的是：认字只看一块区域、点完等画面停住、进行中认出「自动寻路」就不按 Esc、出错留最近几张图、同一个按钮点太多次就停这一路。下面这些先记着。

## 途中会挡住的弹窗

师门和宝图跑起来之后，除了现在用 Esc 关的海报，还可能遇到这些。现在仍是画面中心停住才按一次 Esc。哪一个 Esc 关不掉，再单独加一条。

| 画面 | 别人怎么关 |
| --- | --- |
| 九转天阶 | 按 Esc |
| 九幽地狱 | 点右上角关闭 |
| 战斗平衡 | 点关闭 |
| X9 联赛 | 点关闭。咱们已经用「前往报名」「联赛手册」认海报 |
| 三界热点 | 底部有「点击下方空白处关闭界面」，点那一行。常见错字是「点击下万空白处关闭界面」 |
| 跳过剧情 | 点快进 |

活动两个字有时会被认成「舌动」。主界面改看右下角包裹图标，不靠这两个字，也不靠左上角颜色。左上角颜色太松，福利弹窗盖不住那一块，会被当成已经在主界面。

## 任务栏只能用来续上，不能用来判断做完

别人的师门是直接点右侧任务栏里的「师门任务」。咱们不这么做：任务栏里有进度，只说明接过，或者做到一半中断了。做完没有，仍看活动列表右侧是「参加」还是「完成」。

以后如果一次任务已经点了参加、人还在跑，任务栏里的条目可以用来点一下续上。不能因为任务栏里没有这行字，就当成今天做完了。列表滚走了也会看不到。

别人判断宝图做完，是任务栏里不再有「宝图任务」，同时不在战斗、也没有「自动寻路」。这只能当提示。记完成仍以活动列表里的「完成」为准。

## 看过但不采用

- 大漠插件、整图特征点匹配。后台点击咱们已经用窗口消息，Esc 和滚轮的例外也写好了。
- 模拟器上的固定像素滑动。活动列表在给定范围内按像素缓慢拖动，光标不拖出这块。账号列表仍用滚轮。
- 用四个点的颜色判断人物在移动，静止十几秒就当成任务做完。咱们用画面中心是否停住来决定按不按 Esc，完成看结算或活动列表。
- 宝图从小地图找店小二再点过去。那是任务内部寻路，还没到做的时候。

## 出错处理和调度

`AzurLaneAutoScript` 能长时间挂着，靠的是调度和出错后的处理，不只是认画面。下面这些现在不做。

- 任务排时间。做完一个日常，按成功间隔或固定时刻安排下一次，失败用另一档间隔。服务器维护时先等，恢复后再开。咱们现在是监控台点一次开始，跑完这一轮就停。
- 卡住就重启游戏客户端，连点同一个按钮太多次也重启。咱们只停这一路，并留下最近几张图。不杀游戏进程，也不退出执行器。执行器还要接着给监控台看状态。
- 同一任务连续失败三次就通知人，并退出整个程序。通知渠道以后可以加。退出整个执行器不行，会把别的路一起停掉。
- 按角色等级和队长、队员，从一张任务表里排今天做什么、每项大概多久。`Maa_MHXY` 用角色画像和活动日历做这件事。五开和多任务排期时再做。
- 一个程序里管很多路的启停。五开时再做，现在只有一路。
