# 秘境降妖流程

比例都是客户区比例，含标题栏，顺序是左、上、右、下。点框时点中心。图标相似度 0.85 以上算对上。和图标同一大小去对，客户区保持宽 1024。对不上就留下截图和原因，停这一轮，不退出执行器。

监控页选了秘境降妖才做，不跟在师门或宝图后面。请自己先登录并停在主界面。还没有角色 ID 时，先认角色，步骤和师门相同。

代码在 `mh/runner/app/tasks/mijing.py`。打开活动列表和翻页与师门相同，用 `open_daily_list` 和 `browse_list`。主界面仍是右下角包裹图标。

图标：`app/assets/秘境降妖.png`、`云乐游.png`、`秘境选择.png`、`秘境选关.png`、`秘境-新技能.png`、`秘境-失败.png`。自动战斗用 `自动战斗螺母.png`，和宝图同一块右下角。中间那块有没有变用 `region_same`，相似度 0.97 算没变。

进本之后不操作寻怪，只判断还在不在打。明确失败或通关才离开并停。点了「进入战斗」或画面还在变，就回到每 10 秒的判断。

## 步骤

1. 和师门一样打开日常活动，在列表里用秘境降妖图标匹配。只在 `[0.224, 0.237, 0.936, 0.684]` 里找。四张都没有，停，原因是「活动列表里没有找到秘境降妖」。
2. 这张卡没有「完成」按钮。活跃跟着卡片走，相对图标横向 2.6 到 4.0 个图标宽、纵向 0.5 到 1.0 个图标高。普通是「x/25」，带推荐时给双倍，写成「x/50」。斜杠被拆成两段也认。后面的数不是 25 或 50 就停，原因是「没有读到秘境活跃」。x 达到后面的数才算满：25 满的是 25，50 满的是 50，不把 50 和 25 比。满了就记下今天的秘境，按 Esc 回到主界面，然后停。
3. x 小于 25：点右侧橙色「参加」的像素重心。等 5 秒。在 `[0.010, 0.600, 0.349, 0.971]` 里用云乐游图片匹配。对不上就停，原因是「没有看到云乐游」。对上了就点 `[0.708, 0.476, 0.953, 0.537]` 的中心。
4. 等 2 秒。整张图用秘境选择图片匹配。这是每周一次的选副本窗口。对上就点 `[0.190, 0.800, 0.359, 0.859]` 的中心，再等 2 秒，点 `[0.536, 0.586, 0.652, 0.642]` 的中心。对不上就跳过。
5. 再等 2 秒。整张图用秘境选关图片匹配。对不上就跳过，再等 2 秒去看新技能。对上了就认 `[0.473, 0.245, 0.660, 0.287]`，文字像「剩余挑战次数：2次」。认不出数字就停。次数是 0：记下今天的秘境，按 Esc 回到主界面，然后停。不是 0：点 `[0.814, 0.781, 0.874, 0.857]` 的中心，等 2 秒。
6. 整张图用秘境新技能图片匹配。对不上就停，原因是「没有看到秘境新技能」。对上了就点 `[0.768, 0.389, 0.993, 0.488]` 的中心，进入自动寻怪。
7. 之后每 10 秒截一张。先认 `[0.722, 0.627, 0.946, 0.679]`，里面有「进入」和「战斗」就点这块中心，然后继续看。多认出一个「战」也算。没有的话再看右下角 `[0.910, 0.864, 0.999, 0.977]` 的自动战斗螺母。对上就是还在自动战斗，重新计数。连续两次都对不上，把这两张图的 `[0.782, 0.193, 0.994, 0.379]` 做比较。相似度达到 0.97 算变化不明显，按停下处理。没达到就是还在进行，10 秒后再看。
8. 停下时按这个顺序看，都不是就回到第 7 步：
   - 整张图对上 `秘境-失败.png`：按一次 Esc 关掉失败弹窗，点 `[0.893, 0.493, 0.986, 0.538]` 的中心离开。回到主界面就停，不记完成。
   - `[0.768, 0.417, 0.834, 0.471]` 里有「通关」：点同一块离开。回到主界面就记下今天的秘境并停。

## 停住时监控页上的原因

| 原因 | 发生在 |
| --- | --- |
| 活动列表里没有找到秘境降妖 | 四张列表图都没有图标 |
| 没有读到秘境活跃 | 卡片在，红框里没有 x/25 或 x/50 |
| 秘境已完成，已回到主界面 | 活跃已满（25 或双倍的 50），或剩余挑战次数是 0，并回到主界面 |
| 没有看到云乐游 | 点了参加，5 秒后左下角对不上云乐游 |
| 没有读到剩余挑战次数 | 选关页在，那一块没有「N次」 |
| 没有看到秘境新技能 | 选关之后对不上新技能 |
| 没有回到主界面 | 已完成，Esc 后包裹图标没回来 |
| 已进入自动秘境 | 点了新技能，开始每 10 秒看 |
| 自动战斗中 | 右下角对上了自动战斗螺母 |
| 不在自动战斗 | 这一次没对上螺母，还要再看一次 |
| 秘境进行中 | 连续两次不在战斗，但中间那块变了 |
| 已点击进入战斗 | 某次截图里认到「进入战斗」并点了 |
| 秘境失败，已回到主界面 | 对上失败图，离开后回到主界面。不记完成 |
| 秘境已通关，已回到主界面 | 认到「通关」，离开后回到主界面，并记下完成 |

打开活动列表时的「不在主界面」「活动弹窗没有打开」和师门相同。
