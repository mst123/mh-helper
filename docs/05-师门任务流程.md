# 师门任务流程

比例都是客户区比例，含标题栏，顺序是左、上、右、下。点框时点中心。颜色每个通道相差不超过 40 算同一块。对不上就留下截图和原因，停这一轮，不退出执行器。

代码：`mh/runner/app/tasks/shimen.py`。列表拖动在 `toolkit/scroll.py` 的 `browse_list`。图标和按钮颜色在 `toolkit/match.py`。主界面在 `toolkit/screen.py` 的 `on_state_a`，用 `app/assets/包裹-主页面.png` 对右下角。师门图标是 `app/assets/shimen.png`。

请自己先登录并停在主界面。监控页选师门。这一路还没有角色 ID 时，才先认角色，再进下面的步骤。已经有 ID 就跳过认角色。

## 认角色

只在没有角色记录时做。代码在 `tasks/character.py`。

1. 右下角包裹图标对上就是主界面，不再按 Esc。对不上才按 Esc 关掉挡着的窗口。
2. 点右上角头像。在 `[0.197, 0.229, 0.339, 0.318]` 里读 ID 和名字。
3. 没读到 ID，点属性框 `[0.919, 0.292, 0.964, 0.408]` 的中心，再读一次。头像最多点 3 次。
4. 点信息框 `[0.920, 0.434, 0.964, 0.554]` 的中心。在 `[0.558, 0.236, 0.723, 0.299]` 里读门派。这两个页签不认字。
5. 按一次 Esc 关掉人物面板。右下角包裹图标回来，才继续师门。

## 进师门

1. 看主界面。右下角 `[0.899, 0.805, 0.999, 0.941]` 用包裹图标对上就往下走，不再按 Esc。对不上最多按 3 次 Esc，每次隔 0.5 秒再看。仍对不上，停，原因是「不在主界面」。
2. 点活动框 `[0.282, 0.086, 0.327, 0.135]` 的中心，约 (0.3045, 0.1105)。
3. 最多看 6 次，每次隔 0.4 秒。`[0.450, 0.166, 0.550, 0.228]` 里从左到右拼起来有「活动」就算打开。两个字中间有空、被拆成「活」和「动」也算。没有就停，原因是「活动弹窗没有打开」。
4. 点日常活动框 `[0.066, 0.245, 0.205, 0.309]` 的中心，约 (0.1355, 0.277)。等 0.4 秒。
5. 在列表范围 `[0.228, 0.240, 0.938, 0.686]` 里找师门卡片。找到就停，不再继续翻。四张都没有，停，原因是「活动列表里没有找到师门任务」。
6. 卡片右侧是「完成」：记下今天的师门，按 Esc 直到右下角包裹图标回来，然后停。回不去，原因是「没有回到主界面」。
7. 卡片右侧是「参加」：点按钮颜色的中心。最多看 8 次，每次隔 0.4 秒。`[0.210, 0.273, 0.252, 0.315]` 接近 236,168,115 才算师门弹窗打开。对不上就停，原因是「师门弹窗没有打开」。
8. 弹窗颜色已经对上，不等画面停住。在 `[0.296, 0.587, 0.903, 0.654]` 里点「去完成」或「继续任务」。两个都没有就停。
9. 等 1.2 秒再看福利。有就先按一次 Esc。仍在就点关闭框 `[0.937, 0.204, 0.960, 0.246]` 的中心，约 (0.9485, 0.225)。还在就停，原因是「福利窗口没有关掉」。没有福利弹窗，直接进入下一步。
10. 每 20 秒截一张，和上一张比。中下这块变了，说明还在跑，继续等。没变时看完成色：对上就记今天的师门，按两次 Esc，右下角包裹图标回来就停。对不上就当成活动弹窗，按一次 Esc，换一张新图当基准，继续每 20 秒看。按了两次 Esc 还没回到主界面，停。

监控页上会显示「师门进行中」。点停止或暂停会在这一轮等待里停下来。

## 列表怎么翻

`browse_list` 给以后的长列表用。师门把上面的列表范围和 `shimen_card` 传进去。

光标按下的位置在框内横向正中。向下拖（把列表拉回更靠前的条目）从框的上沿按下；向上拖从框的下沿按下。拖动距离如果超出框的高度，就收到框内，不拖出这块。拖的时候游戏窗口会短暂到前台，光标用完放回。

1. 从上往下拖 250px，约 0.3 秒，做两次。这两次不截图，用来确保在头部。
2. 截图 1，找图标。
3. 从下往上拖 250px，用 1 秒。截图 2，再找。
4. 再从下往上拖 250px，用 1 秒。截图 3，再找。
5. 还没有，再从下往上拖 100px，大约 0.4 秒，截图 4。

游戏列表有加速。翻页故意拖满 1 秒，避免一下甩过头。回头部可以快，因为不靠那两张图认字。

## 怎么认出师门卡片

用 `shimen.png` 只在活动列表 `[0.224, 0.237, 0.936, 0.684]` 里匹配，相似度 0.85 以上算找到。图标和截图同一大小，客户区保持宽 1024。

按钮不认字。从图标右边缘往右，3.0 到 4.7 个图标宽度、图标高度 10% 到 90% 的那一块：

- 橙色像素多，而且至少 40 个，是「参加」。
- 绿色像素多，而且至少 40 个，是「完成」。

点击点是这些像素的中心。这块收窄，是为了不点到同一行另一张卡片，也不把卡片上的「活跃」绿字当成完成。

## 福利和完成

福利满足一条即可：

- `[0.132, 0.521, 0.264, 0.581]` 接近 220,115,53。
- `[0.455, 0.198, 0.554, 0.242]` 里有「福利」，或者分开的「福」和「利」。

进行中的「没变」：`[0.397, 0.576, 0.583, 0.766]` 和上一张的相似度达到 0.97。

完成色：`[0.364, 0.351, 0.627, 0.424]` 接近 221,164,84。对上才按两次 Esc。不对上只按一次，然后继续看，不把这一轮停掉。

## 停住时监控页上的原因

| 原因 | 发生在 |
| --- | --- |
| 不在主界面 | 按了 Esc 仍对不上右下角包裹图标 |
| 活动弹窗没有打开 | 点了活动，标题里没有「活动」 |
| 活动列表里没有找到师门任务 | 四张列表图都没有图标 |
| 没有回到主界面 | 列表已是完成，Esc 后颜色没回来 |
| 师门弹窗没有打开 | 点了参加，弹窗颜色没对上 |
| 师门弹窗里没有「去完成」或「继续任务」 | 弹窗颜色对了，那一条字没有 |
| 福利窗口没有关掉 | Esc 和关闭框之后福利还在 |
| 师门已完成，按了两次 Esc 还没回到主界面 | 完成色对了，两次 Esc 后颜色没回来 |
| 师门已完成，已回到主界面 | 列表已是完成，或进行中看到完成色并回到主界面 |

状态变成「未知界面」「截图失败」或「需要人工」时，最近几张图写到 `data/slots/这一路/error/`。执行器继续开着。
