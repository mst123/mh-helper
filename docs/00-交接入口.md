# 交接入口

把这一份交给新的 AI。先只读本文件。本文件点名要打开的主题文档时，再打开那一份。不要把 `docs/` 下所有文档一次性读完。

## 项目是什么

给梦幻西游手游做客户端稳定性测试。用模拟点击完成日常和周常。游戏跑在网易提供的 Windows 客户端里，一台电脑同时开 5 个客户端，并用一个本地页面看每个账号的进度。个别客户端跑在沙盒里，沙盒的截图和点击要单独处理。

操作路径只有：按该窗口截图、识别画面、把点击送进该窗口。不读游戏内存，不改安装包，不重放协议。

使用者原来是前端高级开发，熟悉 Vue，现在做测试。回复用中文。

## 现在到哪了

- 第一期代码在 `apps/runner`（执行器）和 `apps/console`（监控台）。规格仍在同级 `docs/`
- 已能按窗口标题找一个客户端、截取客户区，并在配置打开点击时把单击送进窗口。监控台有进度卡片，可以开始、暂停、停止
- 还没做 5 路同时跑、沙盒内点击代理、登录状态机和玩法脚本
- 还没有 Git 仓库。不要提交 `apps/runner/data/`、`apps/runner/.venv/`、`apps/console/node_modules/`
- 对话记录不会跟着 Git 走。换电脑之后以这些文档和 `apps/` 里的代码为准

## 已定决策

- 一台电脑，5 个网易 Windows 客户端，每个客户端绑定一个账号。不用模拟器
- 客户端窗口化，客户区尺寸一致。点击送进目标窗口，不用电脑鼠标
- 个别客户端跑在沙盒里。沙盒外的点击或截图若打不进去，这一路改走沙盒内代理，其他路继续
- 两个程序：Python 执行器、Vue 3 监控台。报告和详情是监控台里的页面
- 监控台：Vue 3 + TypeScript + Vite + Element Plus + Vue Router + Pinia
- 执行器：Python 3.11 + 按窗口截图和点击 + RapidOCR + FastAPI + WebSocket + SQLite
- 玩法步骤用 YAML 状态机
- 进度页同一屏 5 张卡片，某一路暂停不影响其余路
- 代码目录是 `apps/runner` 与 `apps/console`，规格文档在同级 `docs/`

这些决策的细节在主题文档里。本段只保留结论。结论变了就改本段，并在文末变更记录加一行。

## 换电脑时

代码和文档都在当前目录：`docs/` 是规格，`apps/` 是程序。一起带走，不要再另建一套目录。

执行器：在 `apps/runner` 用 `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`。窗口标题写在 `config.example.yaml`，本机覆盖可复制成 `config.yaml`。点击默认关闭。

监控台：在 `apps/console` 执行 `npm run dev`，浏览器打开 Vite 地址。

五开、沙盒代理和完整登录状态机仍后做。单路会进入主界面，先记下角色 ID 和门派，再按活动列表里师门任务右侧的「参加」或「完成」决定做不做。见 `03-技术选型.md` 的「先做哪些」。

## 文档怎么加载

组织形式借鉴 skill：入口文件始终先读，主题文件按任务打开。

| 文件                  | 什么时候打开                   |
| ------------------- | ------------------------ |
| `00-交接入口.md`        | 每次新对话                    |
| `01-业务层拆解.md`       | 要改测什么、日常周常、账号分组、通过或失败的标准 |
| `02-自动化测试软件功能拆解.md` | 要改软件功能、进度页内容、五开隔离、异常恢复   |
| `03-技术选型.md`        | 要建仓库、选库、写执行器或 Vue 监控台    |
| `04-以后可能用到.md`     | 要看别的项目里先记下来、现在还不做的做法    |

一次任务通常只需要其中一份。例如「把监控台改成 Vue」只改 `03` 和本文件的已定决策，不必重读业务拆解。

## 需求变更时

先改拥有该需求的主题文档，再改代码。

- 结论变了：改主题文档里的对应章节，并改本文件「已定决策」里的那一条
- 只是细节补充：只改主题文档，本文件不动
- 新增一类需求：新写一个带 `name` 和 `description` 的主题文档，并在上面的表里加一行
- 在本文件文末追加变更记录：日期、改了哪份文档、一句话结论

不要把所有历史对话合并进一个长文件。入口保持短，方便每次都加载。
