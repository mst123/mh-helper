# 宝图任务流程

比例都是客户区比例，含标题栏，顺序是左、上、右、下。点框时点中心。图标相似度 0.85 以上算对上。和图标同一大小去对，客户区保持宽 1024，不按窗口放大模板。对不上就留下截图和原因，停这一轮，不退出执行器。

监控页选了宝图才做，不跟在师门后面。请自己先登录并停在主界面。这一路还没有角色 ID 时，先认角色，步骤和师门相同，代码在 `tasks/character.py`。已经有 ID 就跳过。

代码在 `mh/runner/app/tasks/baotu.py`。打开活动列表用 `toolkit/activity.py` 的 `open_daily_list`，师门也用这个。列表拖动用 `browse_list`。卡片用 `icon_card`。主界面用 `on_state_a`，右下角 `[0.899, 0.805, 0.999, 0.941]` 对 `app/assets/包裹-主页面.png`。

图标文件：`app/assets/宝图任务.png`、`app/assets/店小二.png`、`app/assets/自动战斗螺母.png`。

这一段做到「主界面上已经不是宝图任务」就停。不认次数。寻路和战斗内部先不做，只判断画面落在战斗页、主界面，还是别的窗口。

## 打开活动列表

和师门相同。

1. 右下角包裹图标对上就往下走，不再按 Esc。对不上最多按 3 次 Esc，每次隔 0.5 秒再看。仍对不上，停，原因是「不在主界面」。
2. 点活动框 `[0.282, 0.086, 0.327, 0.135]` 的中心，约 (0.3045, 0.1105)。
3. 最多看 6 次，每次隔 0.4 秒。`[0.450, 0.166, 0.550, 0.228]` 里从左到右拼起来有「活动」就算打开。没有就停，原因是「活动弹窗没有打开」。
4. 点日常活动框 `[0.066, 0.245, 0.205, 0.309]` 的中心，约 (0.1355, 0.277)。等 0.4 秒。

## 找到宝图卡片

翻页和师门相同：先快拖回头部，再按 250px、1 秒向上翻，看三张；没有再挪 100px。范围是 `[0.228, 0.240, 0.938, 0.686]`。

`宝图任务.png` 只在 `[0.224, 0.237, 0.936, 0.684]` 里匹配。底下活跃奖励的卷轴不在这块里。四张都没有图标，停，原因是「活动列表里没有找到宝图任务」。

按钮不认字，规则和师门相同。从图标右边缘往右，3.0 到 4.7 个图标宽度、图标高度 10% 到 90%：橙色至少 40 像素且多于绿色，是「参加」；绿色至少 40 像素且多于橙色，是「完成」。点击点是这些像素的中心。

1. 右侧是「完成」：记下今天的宝图，按 Esc 直到右下角包裹图标回来，然后停。最多 4 次，每次隔 0.5 秒。回不去，原因是「没有回到主界面」。
2. 右侧是「参加」：点按钮中心。不再认「次数 x/10」。已经和店小二对过话时，点参加也会直接开始，所以不能靠次数决定要不要再点对话。

## 点参加之后

最多等 3 秒，每 0.4 秒看一次。活动标题还在时，不认任务名，避免把列表里的「宝图任务」当成已经开始。

1. 列表关掉后，`[0.787, 0.255, 0.877, 0.299]` 从左到右拼起来正好是「宝图任务」：已经自动开始，进入下面的循环。
2. 3 秒内没有这四个字：在 `[0.057, 0.720, 0.277, 0.948]` 里用 `店小二.png` 匹配。对不上就停，原因是「没有看到店小二」。对上了就点 `[0.718, 0.476, 0.947, 0.538]` 的中心，约 (0.8325, 0.507)，再进入循环。

## 自动打宝图时怎么看

先等 15 秒，让画面离开活动列表。之后：

1. 右下角 `[0.910, 0.864, 0.999, 0.977]` 对上 `自动战斗螺母.png`：还在自动战斗。隔 15 秒再从这一步看。
2. 螺母对不上，右下角包裹图标对上：认 `[0.787, 0.255, 0.877, 0.299]`。正好是「宝图任务」，还在做，隔 15 秒再从第 1 步看。认不到，或者不是这四个字，记下今天的宝图并停，原因是「宝图已完成，已回到主界面」。
3. 既不是战斗页也不是主界面：记下这一张，等 10 秒再截一张。中下块 `[0.397, 0.576, 0.583, 0.766]` 相似度达到 0.97 算没变。没变就按一次 Esc。变了就不当弹窗，也不按 Esc。两种都马上再截一张，从第 1 步看，不再等那 15 秒。

比较中下块用 `region_same`，师门也用这个。点停止或暂停会在这些等待里停下来。

## 停住时监控页上的原因

| 原因 | 发生在 |
| --- | --- |
| 不在主界面 | 按了 Esc 仍对不上右下角包裹图标 |
| 活动弹窗没有打开 | 点了活动，标题里没有「活动」 |
| 活动列表里没有找到宝图任务 | 四张列表图都没有图标 |
| 没有回到主界面 | 列表已是完成，Esc 后包裹图标没回来 |
| 没有看到店小二 | 点了参加，3 秒内没有「宝图任务」，左下角也对不上店小二 |
| 宝图已完成，已回到主界面 | 列表右侧已是完成并回到主界面，或主界面任务名已经不是宝图任务 |

进行中会看到这些字，任务还在看，不算停住：已点击「参加」、进入自动打宝图、自动战斗中、主界面仍是宝图任务、不在战斗也不在主界面、已按 Esc 关闭弹窗。

状态变成「未知界面」「截图失败」或「需要人工」时，最近几张图写到 `data/slots/这一路/error/`。执行器继续开着。
