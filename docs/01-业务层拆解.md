# 梦幻西游手游稳定性测试：业务层拆解

本文记录用模拟点击做客户端稳定性测试时，业务上要覆盖什么、怎么组织账号，以及日常和周常应该怎么拆。这里谈的是测什么，不谈测试软件本身怎么实现。

## 测试边界

这类测试适合覆盖客户端在真实操作路径上的长时间表现：

- 登录、选服、选角、进入游戏
- 场景切换、自动寻路、对话
- 进入战斗、战斗过程、战斗结算
- 界面来回切换、弹窗打断
- 断线重连、进程退出后再次进入

点击只能确认客户端表现，不能代替服务器测试接口。奖励是否入账、任务计数是否正确、经济系统是否平衡，都不在这套测试的验收范围内。

正式包上的模拟点击会碰到客户端自身的环境保护。内部稳定性测试应使用内部包，在测试服上跑。

## 账号分组

同一批在一台电脑上同时跑 5 个账号，按角色分工，不要 5 个号跑完全相同的脚本。账号池可以多于 5 个，下一批再换另外的号。

| 分组 | 用途 | 重点 |
| --- | --- | --- |
| 低等级号 | 主线、师门、基础副本 | 引导多、界面切换多 |
| 中等级号 | 抓鬼、宝图、秘境、日常副本 | 日常主循环 |
| 高等级号 | 鬼王、周常玩法、帮战或竞技入口 | 长时间战斗和匹配 |
| 脏状态号 | 背包满、任务栏满、有未领奖励 | 异常分支和阻塞 |

一台电脑同时跑 5 个账号：开 5 个网易 Windows 客户端，每个客户端绑定一个账号。点击送进对应窗口，不使用电脑鼠标去点当前获得焦点的窗口。个别客户端可以跑在沙盒里，这一路的连通性单独判断，失败时只停这一路。

## 日常与周常要压到的路径

玩法名会随版本调整。稳定性测试关心的是路径类型，不是把奖励刷满。

| 类型 | 代表玩法 | 重点压到的客户端路径 |
| --- | --- | --- |
| 日常短循环 | 师门、宝图、运镖、帮派任务 | 反复对话、寻路、交任务 |
| 日常战斗 | 抓鬼、秘境、日常副本 | 进战、回合、结算、再进战 |
| 周常 | 周常副本、门派闯关、竞技或帮战入口 | 匹配、长战斗、场景切换 |
| 活跃收尾 | 签到、活跃领奖、背包整理 | 界面堆叠和奖励弹窗 |

公共路径先统一，再按玩法填差异：

1. 接任务
2. 寻路
3. 对话或进入副本
4. 战斗
5. 结算
6. 交任务
7. 确认完成

每条流程做成独立状态机，不要写成一条从头到尾的长脚本。断线或重进后，先判断任务是否还在，再决定继续或重新接取。

## 业务侧必须处理的干扰

日常被打断，常见原因是界面而不是战斗逻辑。下面这些都要能识别，并在处理完后回到原任务：

- 活动推送、限时玩法入口
- 升级、成就、奖励领取
- 好友、帮派邀请
- 月卡或运营弹窗
- 未看完的引导

处理不了的弹窗记为阻塞，并留下截图。不要在错误界面上连续点击。

## 战斗与寻路的业务策略

稳定性测试不追求最优打法。

- 战斗使用游戏内自动战斗。脚本只确认是否进战、是否卡住、是否正常退出、回合是否异常变长。
- 寻路使用游戏内自动寻路。脚本负责点任务或点 NPC，再确认人物开始移动、到达、进入下一段对话。
- 要记录的缺陷包括：卡在空气墙、寻路中断、无法进战、结算界面不消失。

## 业务异常与恢复顺序

至少覆盖：

- 进程崩溃、无响应、闪退回桌面
- 断线、重连、顶号、登录失效
- 卡在对话、卡在寻路、卡在战斗结算
- 背包满、任务满、等级或次数不够，入口不可点
- 意外进入活动、观战、摆摊或全屏过场

恢复顺序固定为：

1. 截图
2. 记日志
3. 尝试回到主界面
4. 仍失败则重启客户端，再恢复该账号进度

同一账号连续失败要停掉该账号，避免一个死循环拖住其余实例。5 个实例里某一个挂起或停止时，另外 4 个继续跑。

未开放的玩法记为「未开放」，不要记成失败。日常和周常的开放时段不同，调度时要能跳过。

## 业务结果怎么判

每个账号、每条任务留下：

- 开始和结束时间
- 停在哪一步
- 重试次数
- 崩溃次数
- 断线次数
- 关键界面截图

汇总维度是「账号 × 任务 × 结果 × 证据」。结果只分四类：通过、阻塞、崩溃、超时。同一步骤在多个号上重复出现，才当成稳定性问题。

## 一次只跑一个任务

监控页选择师门或宝图，默认师门。执行中和暂停时不能换任务。开始时这一路还没有角色 ID，才点头像记录。有记录就直接做选中的那一个。做完回到状态 A 并停止，师门做完不接着做宝图。

主界面看右下角 `[0.899, 0.805, 0.999, 0.941]`，用包裹图标对上才算，不再看左上角颜色。点开头像后，ID 和名字只认 `[0.197, 0.229, 0.339, 0.318]`。没读到就点属性框 `[0.919, 0.292, 0.964, 0.408]` 的中心。然后点信息框 `[0.920, 0.434, 0.964, 0.554]` 的中心，门派只认 `[0.558, 0.236, 0.723, 0.299]`。这两个页签不认字。

请自己先登录，停在主界面。启动器或登录页会停住，并提示先进入主界面。活动弹窗仍按 Esc 关掉。

「清除当前角色」忘掉这一路记下的 ID，下次开始重新读头像。角色档案仍按 ID 留在本地。「清除今日完成」只清这个角色今天的完成标记。游戏里活动列表已经是「完成」时，清了本地也不会再点「参加」。这两个按钮在执行中和暂停时不能点。

## 师门怎么进

从主界面打开活动列表，用图标找到师门。列表已是完成就回到主界面并停。是参加就点下去完成或继续任务，关掉福利弹窗，然后每 20 秒看画面。完成色出现就按两次 Esc 回到主界面。对不上就留下截图和原因，停这一轮，不退出执行器。

逐步的比例、拖动和停住原因写在 `05-师门任务流程.md`。改师门以那一份为准。

## 宝图怎么进

监控页选了宝图才做。打开活动列表的方式和师门相同。用宝图图标找卡片，右侧是完成就回到主界面并停。是参加就点参加，不再认次数。点完后看主界面任务名是不是「宝图任务」：是就说明已经自动开始；不是再等店小二并点对话。之后隔 15 秒看：右下角有自动战斗螺母，或主界面任务名仍是「宝图任务」，都算还在做。两边都不是就等 10 秒，中下块没变就按一次 Esc。主界面上认不到宝图任务就记完成并停。

逐步的比例和停住原因写在 `06-宝图任务流程.md`。改宝图以那一份为准。寻路和战斗内部这一段不做。

## 秘境怎么进

监控页选了秘境降妖才做。打开活动列表和师门相同。这张卡没有完成按钮，看活跃 x/25，推荐双倍时是 x/50，满的是后面那个数。没满就点参加，等云乐游并点对话。每周的选副本窗口有就点，没有就跳过。选关页剩余次数是 0 也记完成。不是 0 就点进入，新技能对上后点进去。之后每 10 秒看自动战斗。连续两次不在，而且中间那块没变，才区分手动进战斗、失败和通关。失败离开后不记完成。通关离开后记完成。其余情况继续看。

逐步的比例和停住原因写在 `07-秘境降妖流程.md`。改秘境以那一份为准。

## 业务落地顺序

1. 单账号跑通：启动、登录、识别主界面、关掉一层弹窗、完成一轮师门。
2. 补异常：杀进程后重进、断线重连、弹窗打断后回到任务。
3. 扩到一台电脑上的 5 个 Windows 客户端：同时开跑，并在进度页上看每个账号停在哪一步。若其中有沙盒客户端，先确认这一路能截到图、点得进去。
4. 再加抓鬼、副本、周常。每加一个玩法，只新增该玩法的状态机。
